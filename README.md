# Kaly

Kaly es una aplicación móvil para buscar y reservar
alojamientos. Las reservas se pagan en línea.

Para iniciar Expo descartando la caché de Metro, ejecuta `npm run start:clean`.
Úsalo si aparece un error de versiones del plugin de Worklets después de
cambiar o reinstalar dependencias. Las versiones de Reanimated y Worklets
deben coincidir con las recomendadas para el SDK de Expo del proyecto.
